# Production Planning Table Rules

Create the production planning table before image or PPTX generation. Record narrative, content, source assets, source-asset geometry, and the AI-selected layout archetype.

Required columns:

1. slide number;
2. slide title;
3. narrative section;
4. communication task;
5. source asset(s);
6. source-asset geometry;
7. core message;
8. selected layout archetype ID;
9. density level: low / medium / high;
10. asset handling: preserve / overview+detail / split / cross-slide / not-use / request-higher-resolution;
11. notes and risk: fact check, readability, translation, missing asset, etc.

Keep the table concise. Record layout intent without exact geometry coordinates.

Select body-layout archetypes from the new slide's communication task, evidence relationships, source geometry, density, readability, and deck rhythm. The layout selection belongs to scholar-ppt-cn, not to the reference/template deck.

When a visual reference or template is active, use its Template DNA to style the selected layout consistently. When editable native assets are available, reuse them inside or around the AI-selected layout where appropriate.

Do not map scientific content slides to old template/result/discussion/data/microscopy page layouts unless the user explicitly identifies a source page whose layout should be preserved or reused. Stable frame pages such as cover, table of contents, section divider, and closing pages may retain their source structure when appropriate.
