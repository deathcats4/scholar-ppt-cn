# Mockup-Derived Archetype Rules

When approved mockups exist, they override the fallback layout library.

After mockup approval, internally derive archetypes from approved mockups.

For each archetype, record:
- source approved mockup ID;
- communication purpose;
- fixed visual elements;
- adaptable elements;
- source-material region behavior;
- interpretation-region behavior;
- caption/source-note behavior;
- footer/page-number behavior;
- density range;
- suitable content types;
- forbidden misuse.
