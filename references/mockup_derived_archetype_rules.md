# Mockup-Derived Archetype Rules

Approved mockups override fallback aesthetic defaults, not the builder's
content-driven composition judgment.

Derive a reusable archetype only when a communication behavior repeats and the
abstraction improves production. Do not automatically convert every approved
mockup into a page stencil.

For each archetype, record:
- source approved mockup ID;
- communication purpose;
- design behaviors to preserve;
- adaptable composition regions;
- source-material region behavior;
- interpretation-region behavior;
- caption/source-note behavior;
- footer/page-number behavior;
- density range;
- suitable content types;
- alternative composition responses;
- forbidden misuse.

Treat source geometry and recorded proportions as examples rather than required
coordinates. If current evidence does not fit, preserve the communication
behavior and visual identity while creating a different editable composition.
