# Source-Asset Geometry Rules

Classify source assets before choosing a layout archetype.

Types:

- wide figure;
- tall figure;
- square / near-square figure;
- dense multi-panel figure;
- photo / microscopy / image evidence;
- chart / graph;
- table;
- process / mechanism diagram;
- map / spatial figure;
- screenshot / UI / document excerpt;
- no primary source asset.

The chosen layout should fit the asset. Do not force all assets into a single left-image/right-text structure.
