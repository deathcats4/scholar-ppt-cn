# Hidden Narrative Presets

Narrative presets control story order, not page geometry.

## Literature report / journal club

Use for paper/article-based reports.

Default order:
1. Cover
2. Report map / overview
3. Background / introduction
4. Research gap / question
5. Objectives / contribution
6. Study area / materials / data / methods, as appropriate
7. Results / evidence chain
8. Discussion / mechanism / interpretation
9. Conclusions
10. Closing

Default scale:
- 10–15 min: about 14–18 slides;
- complex paper: about 18–24 slides.

## Thesis / defense

Use for thesis/dissertation/degree-defense materials.

Default order:
1. Cover
2. Outline / agenda
3. Background and significance
4. Research status
5. Research gap / scientific or practical question
6. Objectives, contents, and contributions
7. Technical route / data / methods / workload, as appropriate
8. Main chapters or main results in source order
9. Integrated discussion / mechanism / system view
10. Conclusions and outlook
11. Acknowledgements / closing

## Research progress

Use for project progress or recurring group meetings.

Default order:
1. Cover
2. Progress overview
3. Research question / objective
4. Completed work
5. Key results
6. Current problems
7. Next steps
8. Discussion / help needed
9. Closing

## General topical presentation

Use for non-paper, non-defense general presentations.

Default order:
1. Cover
2. Context
3. Problem
4. Main content 1
5. Main content 2
6. Main content 3
7. Summary
8. Closing

## User structure override

If the user provides a preferred order, follow it.
