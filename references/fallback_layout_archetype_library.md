# Fallback Layout Archetype Library

Use this library as an internal vocabulary of composition possibilities for
production planning and editable generation. It is not a mandatory page
catalog, and its labels do not lock geometry.

It is internal. Do not ask the user to manually choose archetypes.

## Contents

- Opening, agenda, background, gap, and objective
- Study area/data and methods
- Single-figure, multi-panel, chart, and table evidence
- Comparison, mechanism, discussion, and conclusions
- Closing pages and selection rules

## Opening / cover

O1. Strong title block + small source/context line + restrained visual motif.
O2. Left title block + right source-material collage or abstract frame.
O3. Center title + institutional/header/footer emphasis.

## Report map / agenda

A1. Numbered vertical agenda with brief subtitles.
A2. Horizontal process/section timeline.
A3. Two-column agenda: context/results/discussion.

Avoid figures unless the user explicitly wants visual agenda.

## Background / context

B1. Claim-first top statement + two evidence/context cards.
B2. Large contextual figure + brief interpretation strip.
B3. Three conceptual cards + small supporting source asset.
B4. Problem funnel: broad context -> specific issue -> report focus.

## Research gap / question

G1. Contrast layout: known / unknown / this work.
G2. Central question statement + three supporting gaps.
G3. Source figure or quote region + interpretation cards.
G4. Problem-to-objective flow.

## Objective / contribution

C1. One main objective + three contribution cards.
C2. Evidence-chain overview with method/result/discussion blocks.
C3. Objective left + source-material roadmap right.

## Study area / materials / data

S1. Full-width map/spatial figure + bottom interpretation row.
S2. Large left source figure + right metadata cards.
S3. Two source assets side-by-side + compact explanation.
S4. Data/material matrix with small visual anchor.

## Method / workflow

M1. Horizontal workflow with 4-6 steps.
M2. Vertical pipeline with source assets on side.
M3. Method table + small process diagram.
M4. Input -> analysis -> output framework.

## Closing

Z1. Thank-you page.
Z2. Contact / source / acknowledgement page.
Z3. Formal ending page matching template identity.

## Selection rules

- Match archetype to source-asset geometry.
- Start from the communication task and real evidence, then adapt or combine
  compatible patterns.
- Vary composition intentionally across long decks; do not rotate patterns
  mechanically.
- Do not use the same skeleton more than twice in a row.
- If a dense source asset is unreadable, use overview + detail zoom or split across slides.
- Apply Template DNA to colors, typography, borders, captions, spacing, header/footer.
- Depart from the listed patterns when none serves the current content. Record
  the layout reason instead of forcing a poor fit.
