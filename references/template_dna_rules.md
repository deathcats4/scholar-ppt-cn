# Template DNA Rules

First record the actual canvas. Preserve a user template or existing deck's
native dimensions. Default to 16:9 only when no source canvas exists.

Extract visual identity:

- title hierarchy and typography roles;
- header, footer, and page-number behavior;
- palette and background behavior;
- caption and source-note style;
- spacing rhythm and density;
- figure/text balance;
- cards, borders, dividers, ribbons, and emphasis language.

Treat Template DNA as identity, not a cage. Do not force identical geometry
unless strict template adherence is explicitly requested.

Use a user template before a built-in preset. Do not automatically select the
legacy reference template.
